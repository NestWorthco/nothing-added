# Nothing Added

Installable web app: scan a food barcode or photograph a label to see how processed it is (5-step scale, purity score, additive codes, estimated life cost), and log what you eat against the NZ/AU Daily Intake values.

Static site, no build step. Barcodes are decoded on the phone (ZXing), label text is read on the phone (Tesseract.js), products are looked up on Open Food Facts, and the log is stored in the browser.
